# Linear Regression Tutorial: From Basics to Advanced

This repository contains a comprehensive tutorial on Linear Regression, covering concepts from basic mathematics to advanced techniques and implementation.

## Project Structure

```
linear_regression_tutorial/
├── data/                    # Data directory for datasets
├── notebooks/              # Jupyter notebooks with tutorials
│   ├── 01_Mathematical_Foundations.ipynb
│   ├── 02_Simple_Linear_Regression.ipynb
│   ├── 03_Multiple_Linear_Regression.ipynb
│   └── 04_Regularization_and_Pipeline.ipynb
├── src/                    # Source code directory
└── requirements.txt        # Python dependencies
```

## Notebooks Overview

1. **Mathematical Foundations** (01_Mathematical_Foundations.ipynb)
   - Linear Algebra Basics
   - Statistics Fundamentals
   - Calculus Concepts

2. **Simple Linear Regression** (02_Simple_Linear_Regression.ipynb)
   - Implementation from scratch
   - Using scikit-learn
   - Model assumptions and diagnostics

3. **Multiple Linear Regression** (03_Multiple_Linear_Regression.ipynb)
   - Multiple Linear Regression implementation
   - Feature Selection Techniques
   - Feature Engineering
   - Model Evaluation

4. **Regularization and Pipeline** (04_Regularization_and_Pipeline.ipynb)
   - Ridge Regression (L2)
   - Lasso Regression (L1)
   - Elastic Net
   - Building a Complete Pipeline

## Setup and Installation

1. Create a virtual environment (recommended):
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

## Prerequisites

- Basic Python programming knowledge
- Fundamental understanding of mathematics and statistics
- Familiarity with NumPy and Pandas (basic level)

## Learning Path

1. Start with the Mathematical Foundations notebook to understand the underlying concepts
2. Move to Simple Linear Regression to learn basic implementation
3. Progress to Multiple Linear Regression for more complex scenarios
4. Finally, explore Regularization techniques and build complete ML pipelines
