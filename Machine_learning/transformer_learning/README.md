# LLMs & Transformers: End-to-End Learning Roadmap

Welcome! This project is a step-by-step, hands-on guide to understanding Large Language Models (LLMs) and Transformers from the ground up. It integrates theory, math, and code, with practical examples and exercises.

---

## Learning Path

### **Phase 1: Fundamentals**
- **What is a Transformer?** (Theory, math, code)
- **Self-Attention:** Intuition, math, code from scratch, visualization
- **Multi-Head Attention:** Why, how, code
- **Positional Encoding:** Theory, math, code, visualization
- **Transformer Encoder:** Putting it all together

### **Phase 2: Real-World Transformers**
- **Using HuggingFace Transformers**
- **BERT:** Theory, math, code, applications
- **Fine-tuning for NLP tasks** (sentiment, NER, QA)
- **Tokenization and preprocessing**

### **Phase 3: Advanced Topics**
- **Pretraining objectives:** MLM, NSP, etc.
- **Scaling up:** LLMs, efficiency tricks, memory, inference
- **Prompt engineering and in-context learning**
- **Explainability and visualization**
- **Limitations and open research**

### **Phase 4: Capstone Project**
- End-to-end workflow: from raw data to fine-tuned model and inference
- Real-world dataset (e.g., sentiment, summarization, chat)
- Model evaluation, error analysis, deployment tips

### **Phase 5: Self-Assessment**
- Quizzes, exercises, and code challenges at each stage

---

## Project Structure

- `notebooks/` – Interactive tutorials and code walkthroughs
- `src/attention/` – Self-attention theory, math, and code
- `src/transformer/` – Transformer encoder implementation
- `src/bert/` – BERT theory, code, and sentiment classifier
- `data/` – Example datasets (to be added)
- `models/` – Saved and pretrained models (to be added)

---

## How to Use This Project

1. **Start with the notebooks**: Follow the order in the roadmap. Each notebook is self-contained and references theory and code modules.
2. **Dive into the `src/` modules**: Read the detailed READMEs and explore the code.
3. **Experiment**: Run and modify the code, try your own examples, and answer the exercises.
4. **Advance**: Progress to BERT, fine-tuning, and LLM topics as you gain confidence.
5. **Capstone**: Complete the end-to-end project and test your understanding with quizzes.
